# 服务器和本地索引

从用户指定的工作区读取 `.server-account-local/servers.md`。如果没有配置，询问本次操作涉及的主机并提供仓库中的配置示例。旧地址只用于识别历史记录。在线查询仅覆盖用户明确配置或指定的服务器。

使用本次指定的管理员用户名，缺省用本地配置中的管理员用户名。保持 SSH 主机密钥校验，连接后将主机短名与配置比对。优先使用获授权的 SSH 密钥或 agent。需要密码时请操作者通过交互认证。SSH 登录与 sudo 分别认证。密码、私钥、认证令牌和密码哈希不得进入命令参数、日志、操作报告或公开文件。

首次在线定位使用精确用户名和 `getent passwd`，只提取所需字段。区分查无此账号、连接失败、主机身份异常与查询失败。全部配置主机都确认无账号才可报告未找到。历史命中不代表其他服务器没有该账号。

将索引保存在工作区的 `.server-account-local/accounts.tsv`，目录权限 700，文件权限 600。每行以制表符记录账号、服务器别名、核验时间和证据来源。同一账号每台服务器各一行。在线核验用带时区的时间；导入旧记录时使用原日期，未知则注明。仅从证据充分的记录索引账号。确认账号已不存在时修正对应主机一行，临时不可达时保留原记录。更新时保留其他记录并原子替换文件。将整个私有目录排除出版本控制。
